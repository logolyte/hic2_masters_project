# Studying role of Hic2 in cellular reprogramming with computational models

Environments:

- ``unitvelo``: Used for the "Unitvelo.ipynb" notebook.

How to replicate the results:
1. ...
2. Run "Convert mtx files to Anndata.ipynb" to convert all mtx files to the anndata object "RNA Sequencing Data/splice_counts.h5ad".
3. Run "SDEvelo.ipynb" for the velocity analysis. The results will be saved to "RNA Sequencing Data/adata_sdevelo.h5ad"
